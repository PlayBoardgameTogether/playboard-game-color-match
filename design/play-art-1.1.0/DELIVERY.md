# PlayBoard 展示美术 1.1.0

本批为 color-match 重绘独立方形头像、横版封面和宽幅背景，共 3 张。默认使用细腻像素风，原稿在本目录的各游戏子目录，完整提示词、原稿/导出摘要和尺寸在 generation.json。使用内置 image_gen 生成，原稿与提示词一并按 GPL-3.0-only 随仓库维护。

运行 PNG 在游戏源目录的 art/play-1.1.0（UNO 毫不留情在 no-mercy 子目录），以独立展示包版本 1.1.0 编号，不覆盖旧图、已发布 ZIP 或旧资源包。平台按审查后的完整提交 SHA 导入，导出 WebP 后用于平台目录、详情头像与背景；它不是规则安装包，也不表示线上已安装新游戏。

Color Match 游戏升级至 1.1.0，增加游戏自有的首页练习渲染器，复用现有教程校验器，不调用账号/对局 API。src/legacy/1.0.0 保留 1.0.0 的原始 shared/server 源字节，独立旧版导出供平台按旧 manifest 和摘要恢复已存在对局；旧资产 manifest 也单独保留。双方规则动作与公开视图已做存档恢复对比。新版构建不会覆盖旧标签，未创建 Release。

- node design/play-art-1.1.0/verify.mjs：校验所有原稿、运行 PNG 的 SHA-256、PNG 尺寸、三种用途和独立展示版本。
- 浏览器检查完整图集、方形头像与横版裁切；卡牌封面中不属于游戏的物件与数字已重新绘制。
- pnpm typecheck、pnpm test（含旧版恢复）、pnpm build、pnpm verify：通过。
- 平台登记的仓库、名称、游戏 ID、包名前缀和玩法已核对，无需改动。平台全站检查与服务运行版本在平台 PR 记录，不将本仓库推送等同于部署。
